# Allevi Recovery

Independent, community-built tools for people who still own an Allevi 3
bioprinter.

## Why this exists

Allevi has [discontinued production of the Allevi
bioprinters](https://www.allevi3d.com/allevi-announcement-discontinued-products/),
effective July 27, 2023, with end of service life on July 27, 2026. If you
still have the hardware, this repo collects small, independent tools to help
you keep using it.

## Tools

- **[Allevi Reconnect](reconnect/)** — reconnects your printer to Allevi's
  own website so it shows as connected instead of offline. See
  [reconnect/README.md](reconnect/README.md) for what it does and how to set
  it up.
- A second tool is in progress and will be added here soon.
